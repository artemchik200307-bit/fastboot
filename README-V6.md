# FASTBOOT v6.0 Manual AI

## Что добавлено

- удалён блок «Статус продукта»;
- рабочее окно «Узнать больше»;
- AUTO/MANUAL режимы AI Assistant;
- интерфейс сигналов и отчётов шести агентов;
- расчёт объёма, маржи, ликвидации, риска и профита;
- единый AI-баланс;
- SQL-миграция для ручных AI-позиций;
- отдельный FastAPI AI Service;
- регулярное сканирование топовых USDT-пар;
- сохранение масштаба и позиции графика терминала.

## Установка сайта

Замените файлы проекта содержимым архива.

## Supabase

Выполните:

`supabase-fastboot-v6-manual-ai.sql`

## AI Service

1. Создайте отдельный Render Web Service из папки `ai-service`.
2. Укажите `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`.
3. После деплоя замените в `dashboard.html`:
   `https://YOUR-FASTBOOT-AI-SERVICE.onrender.com`
   на фактический URL сервиса.

## Важно

Текущий AI Service использует публичные рыночные данные и детерминированные
агентные правила. `GROQ_API_KEY` оставлен как опциональная переменная для
следующего этапа, когда потребуется LLM-анализ текста новостей и объяснений.

Для реальной биржи Execution Service должен использовать API-ключи на сервере,
а не в браузере. В этой версии ручные AI-сделки открываются внутри платформы
через Supabase и общий `bot_balance`.
