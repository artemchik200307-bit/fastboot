# FASTBOOT V7

Изменения:
- автоматические сделки отделены от ручных;
- в ручном режиме отображаются открытые позиции и история;
- в Admin Panel добавлена общая статистика ручной торговли и сделки всех пользователей;
- в карточке пользователя добавлена вкладка «Ручная торговля»;
- AI-сервис анализирует все активные spot-пары Binance к USDT;
- Groq полностью удалён.

## После загрузки проекта
1. Выполнить `supabase-fastboot-v7-trade-separation-admin.sql` в Supabase SQL Editor.
2. Задеплоить frontend.
3. Задеплоить `ai-service` с очисткой build cache.
